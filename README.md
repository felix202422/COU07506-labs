## Overview

This repository contains practical laboratory exercises for **COU07506 – Digital Signal Processing**, undertaken as part of the Computer Engineering programme at the Dar es Salaam Institute of Technology (DIT).

The repository documents the implementation and analysis of digital signal processing concepts using Python, Jupyter Notebook, and relevant scientific computing libraries.

## Objectives

- Understand and implement discrete-time signals.
- Generate and visualize fundamental DSP signals.
- Explore sampling and signal representation.
- Perform basic audio signal acquisition and processing.
- Apply mathematical and computational techniques to DSP problems.
- Develop practical skills in scientific programming and signal analysis.

## Installation and Setup

### 1. Install Python

Download Python from:

https://www.python.org/downloads/

### 2. Install the required libraries

Open a terminal and execute:

```bash
python -m pip install numpy scipy matplotlib jupyter
```

### 3. Launch Jupyter Notebook

```bash
jupyter notebook
```

### 4. Open a laboratory notebook

Navigate to the relevant weekly directory and open the corresponding `.ipynb` file.

## Running the Notebooks

1. Clone the repository:

   ```bash
   git clone https://github.com/felix202422/COU07506-labs.git
   ```

2. Navigate into the repository:

   ```bash
   cd COU07506-labs
   ```

3. Install the required dependencies.

4. Launch Jupyter Notebook.

5. Open and execute the laboratory notebook cells sequentially.
